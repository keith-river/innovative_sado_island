CLASSIFIED MISSION FILE

特命ミッション
佐渡逆転経済作戦

人口流出と地域経済縮小が続く佐渡市。市長と新潟県知事は、手段を択ばぬ辣腕マーケター 「ブレード株式会社 小森」に、島の人口・観光・収支を立て直す全権を与えた。 あなたが小森となり、限られた予算をどの施策に配るかを8ターンにわたって選択する。

🧭
小森からのブリーフィング

「佐渡は人が減り続けている島だ。でも、金・朱鷺・海・港——武器は揃ってる。 後は配分のセンスだけだよ。」

「毎ターン、予算を施策に振り分けてもらう。効果は次のターンにすぐ跳ね返る。 気候変動やSNSバズりみたいな“想定外”も普通に起きるから、そのつもりで。」

RULE 01

予算配分

人口・観光客・産業規模に応じて毎ターン予算が決まる。8種の施策に自由に投資しよう。

RULE 02

連鎖する結果

投資は人口・観光客・収支に反映され、季節変動や突発イベントの影響も受ける。

RULE 03

8ターンで決着

2年分・全8ターンの経営を終えたら、佐渡がたどった経済の道筋を振り返る。
