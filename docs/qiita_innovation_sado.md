# 佐渡島は人口減少を「食」で止められるか？ 地産地消の健康メニュー開発から考える地域経済逆転シミュレーション

Nov 14, 2026 · @keithrive

## はじめに

新潟県佐渡市は、1950年代には12万人を超えていた人口が、現在は5万人を割り込むところまで減り続けている地域のひとつです。人口が減れば一次産業の担い手も、商店も、観光の受け皿も先細りし、経済規模が縮小する。経済が縮小すれば働き口も減り、若い世代がさらに島を出る。この「人口流出→経済縮小→さらなる流出」という悪循環は、佐渡に限らず、多くの地方都市が直面している構図です。

一方で、佐渡には金山の歴史、朱鷺、海、そしておけさ柿をはじめとする豊かな食の資源があります。そこに「健康寿命を延ばす健康食材」という切り口を重ねたとき、地域経済と住民の暮らしの両方に効く一手はつくれるのか——これが今回の試作アプリの出発点にある問いです。

## なぜこのアプリを作ったのか

地方の人口減少対策というテーマは、自治体の報告書や統計データとしてはいくらでも触れる機会があります。しかし「ブランディング投資と観光イベント、どちらを厚くするべきか」「短期的に稼げる資源開発と、時間のかかる一次産品の高付加価値化、どちらを選ぶか」といったトレードオフは、数字の羅列だけではなかなか自分事として実感しづらいものです。

特に気になっていたのは、健康食材や地産地消のような「地味で時間のかかる一手」が、派手な観光施策や資源開発の陰に隠れて軽視されがちなことでした。健康寿命が延びれば医療・介護コストは長期的に下がり、それは地域経済の体力そのものに効いてくるはずです。けれど、効果が出るまでのタイムラグが長いぶん、優先順位を上げにくい。

この「効果の出方の違い」を体感してもらうには、実際に予算を配分し、数ターン先の結果を見てもらうのが一番早いだろうと考え、ブラウザで動く経営シミュレーションとして試作することにしました。

## どんなアプリか

*(ここにメイン画面のスクリーンショットが入ります)*

タイトルは「イノベーション佐渡島 逆転経済」。プレイヤーは、佐渡市長と新潟県知事から特命を受けたマーケター「小森」として、8ターン（ゲーム内の2年間）にわたって島の予算配分を担当します。

選べる一手は8種類。おけさ柿などの特産品ブランディング・EC展開、ライバー移住特区、サブカルチャーイベント、ワーケーション特区、移住者支援、交通インフラ拡充、海外交易港の整備、そして希少資源の採掘——地味で堅実な一手から、一発逆転を狙えるが環境リスクを伴う一手まで、性格の異なる選択肢が並びます。

*(ここに施策選択画面のスクリーンショットが入ります)*

配分した予算は翌ターンの人口・観光客数・収支に反映され、台風や感染症、SNSでの突発的なバズりといった「想定外」のイベントも毎ターン発生します。人口と収支の推移はグラフで可視化され、8ターン終了時には、その島が最終的にどんな経済の道筋をたどったかが総評として示されます。

## 実際に触ってみる

本記事の執筆時点では、常時アクセスできるホスティング済みのデモURLは用意していません。試作段階のため、まずはGitHubからファイルを取得して、お手元のブラウザで動かしてみてください。

1. [GitHubリポジトリ](https://github.com/keith-river/innovative_sado_island) からコードをダウンロード（またはクローン）する
2. HTMLファイルをダブルクリックしてブラウザで開く（サーバー構築やビルド作業は不要）
3. 「ミッション開始」ボタンを押し、8ターン分の予算配分を進めていく
4. 所要時間は3〜5分。最後に表示される総評と、人口・収支の推移グラフを眺めてみる

会場や記事のコメント欄で感想を交換しながら試していただけると、議論のきっかけとして機能しやすくなると思います。

## 触ってみて考えてほしいこと

プレイしてみると、多くの人が「希少資源の採掘」に予算を集中させたくなるはずです。収支が一気に跳ね上がり、ゲームとしては気持ちがいい。けれど環境リスクを示すマークが常に点灯し続け、人口にじわじわとマイナスの影響が出続けます。

一方で、特産品のブランディングや健康食材を軸にした一手は、1ターンあたりの効果は地味です。派手な数字の動きはなく、じっくりターンを重ねて初めて効いてくる。

ここで考えてほしいのは、このゲーム内の構図が、現実の地域経営が抱えるジレンマそのものだということです。

- 短期的に収支を好転させる一手と、時間はかかるが持続可能な一手。あなたの地域なら、どちらに予算を厚くしますか？
- 「健康寿命を延ばす食」のような、効果が数字に表れるまでに時間がかかる施策を、行政や住民はどう評価すればよいのでしょうか。医療費や介護費の抑制という長期的なリターンを、どう「今ここ」の意思決定に織り込めるでしょうか。
- あなたの住んでいる、あるいは出身の地域にも、佐渡のおけさ柿のような「まだ化けていない資源」があるはずです。それは本当に活かされているでしょうか。活かされていないとしたら、それはなぜでしょうか。

答えのないまま終えてしまって構いません。このアプリも、記事も、結論を出すためのものではなく、あなた自身の地域に引き寄せて考え直すための最初の一歩を作ることを目的にしています。コメント欄で、あなたの地域に置き換えた「一手」をぜひ教えてください。

## 技術メモ

実装はHTML5とJavaScriptのみのシングルページアプリで、外部CDNへの依存を持たせていません。オープンキャンパスの会場のように通信環境が不安定な場所でも、ファイルを開くだけで確実に動かせることを優先した設計です。ターンごとの予算は、人口・観光客数・産業規模から次のように概算しています。

```javascript
function currentBudget(state) {
  const ind = state.industries;
  const b = 1200 + state.population * 0.03 + state.tourists * 2
          + (ind.primary + ind.secondary + ind.tertiary) * 10;
  return Math.round(b / 50) * 50;
}
```

## 生成AI活用について

課題設定（佐渡市の人口流出と地域経済縮小、そこに健康食材・地産地消を掛け合わせる切り口）と、ゲームとしての設計思想（8つの一手の性格づけ、短期的な資源開発と地道な一次産品ブランディングを対比させる構成など）は筆者が考えました。実装は生成AIを活用し、対話とレビューを何度も繰り返しながら進めています。出力されたコードや挙動を筆者が確認し、意図した構成になっているかを都度すり合わせたうえで、最終的な内容は筆者が確認・判断して公開しています。

## 留意事項

- 本アプリに個人情報は含まれていません。使用している佐渡市の人口規模などの数値は、一般に公開されている統計を参考にした演出上の概算であり、現実の統計データや市の施策を正確に反映したものではありません。
- 本アプリは試作版（プロトタイプ）です。ゲームバランスや施策の効果は簡略化されたフィクションであり、実際の地域政策の検討材料としてそのまま用いることは想定していません。
- 本アプリは結論を提示するものではなく、地域課題について議論や対話を始めるきっかけとして公開しています。
- アプリ内の感想ボードはどなたでも書き込める仕様のため、不適切な投稿が混入する可能性があります。あらかじめご了承ください。

## おわりに

佐渡のように人口流出に直面している地域は、全国に数多くあります。もし、あなたの住む街で同じような「予算配分ゲーム」を作るとしたら、どんな一手を用意しますか。そしてその一手は、本当に地域を良くするものでしょうか。それとも、ゲームの中の希少資源採掘のように、見た目の数字だけを好転させる一時しのぎに終わってしまうでしょうか。

正解はまだ誰にもわかりません。だからこそ、一度手を動かして、自分の地域に引き寄せて考えてみてほしいと思います。
